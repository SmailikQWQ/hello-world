# hello-world
Вы можете вносить изменения в файлы в репозитории и сохранять их. В GitHubслучае сохраненных изменений называются фиксациями. С каждой фиксацией связано сообщение о фиксации, в котором объясняется, почему было внесено данное изменение. В сообщениях о фиксациях ведется история изменений, чтобы другие участники могли понять, что вы сделали и почему.
